Windows Event IDs · Splunk SPL
Windows Event ID4624 — Successful logonRecords a successful logon. Review the account, logon type, and available source information.
Windows Event ID4625 — Failed logonRecords a failed logon attempt. Useful for reviewing the target account, failure reason, and source information.
Windows Event ID4688 — New process createdRecords creation of a new process. Review the process name, parent process, and command line when command-line auditing is enabled.
Windows Event ID4768 — Kerberos TGT requestedRecords a request for a Kerberos Ticket Granting Ticket (TGT). Useful for reviewing the account, client, and request result.
Windows Event ID4769 — Kerberos service ticket requestedRecords a request for a Kerberos service ticket (TGS). Useful for reviewing the target service, account, and client.
Splunk SPLsearchStart by selecting the data or event you need.index=windows EventCode=4625
Splunk SPLstatsAggregate and count results by a field.index=windows EventCode=4625 | stats count by user
Splunk SPLwhereFilter processed results using a Boolean expression.index=windows EventCode=4625 | stats count by user | where count > 5
Splunk SPLtableDisplay selected fields in a compact table.index=windows EventCode=4624 | table _time user src_ip
Splunk SPLtimechartChart event counts over time. Field names depend on the data source.index=windows (EventCode=4624 OR EventCode=4625) | timechart count by EventCode
