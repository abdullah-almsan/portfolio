مكتبة eJPT للمراجعة العملية

مراجع مرتبة حسب سير العمل للمراجعة أثناء مختبرات eJPT وCTF المصرح بها. المراجع الجديدة PDF ثنائية اللغة، والمراجع القديمة تبقى متاحة كما هي.

طريقة الاستخدام

ابدأ بخارطة القرار، ثم انتقل إلى الاستطلاع والخدمات والويب والاستغلال حسب ما يظهر في المختبر. البطاقة الأساسية لكل مرجع تظهر مرة واحدة؛ الروابط المتقاطعة تنقلك إليها دون تكرار.

للتعلم والمختبرات المصرح بها فقط. استخدم الأوامر ضمن النطاق المسموح.

Windows Event IDs · Splunk SPL
Windows Event ID4624 — تسجيل دخول ناجحيسجل نجاح تسجيل الدخول. راجع الحساب ونوع تسجيل الدخول ومعلومات المصدر المتاحة.
Windows Event ID4625 — تسجيل دخول فاشليسجل فشل محاولة تسجيل الدخول. يفيد في مراجعة الحساب المستهدف وسبب الفشل ومعلومات المصدر.
Windows Event ID4688 — إنشاء عملية جديدةيسجل إنشاء عملية جديدة. راجع اسم العملية والعملية الأب وسطر الأوامر عندما يكون تسجيله مفعّلًا.
Windows Event ID4768 — طلب Kerberos TGTيسجل طلب تذكرة Kerberos Ticket Granting Ticket (TGT). يفيد في مراجعة الحساب والعميل ونتيجة الطلب.
Windows Event ID4769 — طلب Kerberos Service Ticketيسجل طلب تذكرة خدمة Kerberos (TGS). يفيد في مراجعة الخدمة المستهدفة والحساب والعميل.
Splunk SPLsearch — البحثابدأ بتحديد البيانات أو الحدث المطلوب.index=windows EventCode=4625
Splunk SPLstats — التجميعللتجميع والحساب حسب حقل.index=windows EventCode=4625 | stats count by user
Splunk SPLwhere — التصفية بشرطلتصفية النتائج وفق تعبير منطقي بعد المعالجة.index=windows EventCode=4625 | stats count by user | where count > 5
Splunk SPLtable — اختيار الحقوللعرض الحقول المهمة في جدول مبسط.index=windows EventCode=4624 | table _time user src_ip
Splunk SPLtimechart — الاتجاه عبر الزمنلعرض عدد الأحداث عبر الزمن. أسماء الحقول تعتمد على مصدر البيانات.index=windows (EventCode=4624 OR EventCode=4625) | timechart count by EventCode
